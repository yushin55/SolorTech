# 사업성 분석 기능 변경

## 2026-11-16 · 설치 가능 지역을 유형별로 한 지도에 겹쳐 표시

- 이전에는 수상·지상·건축물 중 하나를 찾으면 앞서 찾은 유형이 지도에서 지워졌습니다.
- **이 지역 후보 찾기 → 전체**는 세 유형을 한꺼번에 찾습니다. 찾은 곳은 유형별 색 경계와 아이콘 핀(물결 수상 · 부지 지상 · 건물 건축물)으로 함께 표시하고(핀은 지도를 축소해도 크기가 그대로라 작은 지붕·주차장도 보입니다), 유형 하나만 다시 찾아도 나머지는 남습니다.
- 오른쪽 **설치 가능 지역** 탭에 유형별 개수, 면적 합계, 세부 종류(저수지·주차장·공장 등)별 개수를 표시하고 체크 표시로 유형별 표시를 켜고 끕니다. 한 유형의 검색이 실패해도 나머지 유형은 표시합니다.
- 면적 합계는 지도에 표시된 곳(유형별 면적 큰 순 최대 80곳)의 OSM 경계 면적이며 설치 가능 면적이나 용량·발전량이 아닙니다. 용량과 발전량은 후보지로 추가해 분석해야 나옵니다.
- 서버가 한 번에 받는 범위는 유형마다 다릅니다(수상 0.8°×0.6°, 지상 0.3°×0.2°, 건축물 0.1°×0.08°). 화면은 이 크기의 칸으로 나눠 가운데 칸부터 한 번에 수상 6칸·지상 4칸·건축물 4칸까지 차례로 찾고, 받은 칸부터 지도에 표시합니다. 칸이 남으면 패널에 "가운데 N칸만 찾았습니다"를 표시합니다.
- 찾은 결과는 **찾은 결과 모두 지우기**를 누를 때까지 쌓입니다(같은 OSM 객체는 한 번만). 찾은 범위 밖으로 지도를 옮기면 **이 위치에서 다시 찾기**가 나타나고, 찾는 중에는 **중지**할 수 있습니다. 칸마다 면적이 큰 80곳만 받으므로 넓게 찾으면 작은 곳 일부가 빠집니다.

## 2026-11-16 · 지도 후보 찾기를 수상·지상·건축물로 확장

- 이전에는 지도의 찾기 기능이 OSM 수면만 검색했고, 시작 프로젝트도 경계가 있는 후보지는 저수지 2곳뿐이었습니다. 경계 없는 후보지(아산정수장 실적 재현)는 지도에 그려지지 않아 지도에는 수상 후보만 보였습니다.
- **이 지역 후보 찾기**에 수상·지상·건축물 버튼을 두었습니다. 지상은 유휴 부지·개발 예정지·매립지·채석장·염전·초지·주차장(2,000 m² 이상), 건축물은 외곽 1,000 m² 이상을 찾습니다. 검색 기준과 한계는 [참고 자료](references.md)의 "지상 부지·건축물 후보 경계"에 있습니다.
- 찾은 지상·건축물을 후보지로 추가하면 설치장소 유형과 육상용 기본값이 적용되고, 기본안은 찾은 경계 면적의 70%에 배치합니다(지도 경계 면적 방식).
- 경계 없는 후보지도 위치 핀으로 표시합니다. 핀과 사업성 순위에 유형(수상·지상·건축물·정수장·침전지)을 표시하고, 세 유형을 같은 B/C 기준으로 줄 세웁니다.
- 시작 프로젝트에 예당저수지·탑정호 인근의 건축물 2곳, 지상 부지 2곳을 추가했습니다. 각 검색 범위에서 면적이 가장 큰 곳을 고른 미검증 후보이며 이름과 출처에 그렇게 표시합니다.

## 2026-11-14

## 반영한 기능

- 육상·건축물·수상을 하나의 후보지 목록과 사업성 검토 과정에서 다룹니다. 후보지의 **설치장소 유형**에서 지상(평지/경사지), 건축물, 수상을 선택합니다. 기존 정수장·침전지 유형도 보존합니다.
- 지도 **지도에서 새 위치 선택**으로 좌표를 선택한 뒤 후보지를 저장하거나, **후보지 위치 지정**으로 기존 후보지 좌표와 경계를 함께 이동해 서버에 저장합니다. 위도·경도는 화면에도 표시합니다.
- 기상청 공식 관측 지점 정보의 ASOS 96곳 좌표 스냅샷을 지도 아이콘으로 표시합니다. 파란 아이콘은 발전량 계산에 필요한 일자료를 확보한 관측소입니다. 도시 중심 좌표를 쓰지 않습니다.
- 관측소는 후보지와의 대권거리로 찾습니다. 전체 목록 중 최인접 관측소와 일사·기온 자료가 있는 최인접 연결 관측소를 각각 표시합니다. 좌표를 바꾸면 다시 찾습니다.
- 면적 직접 입력: `floor(면적 × (1 − 여유면적률) ÷ (모듈 폭 × 배치 피치)) × 어레이 세로 단수`로 계산합니다. 행간, 투영 길이, 피치, 통로·장애물 여유 면적, 제원 출처를 미리 보여 줍니다. 직렬 단위는 내림합니다.
- 목표 총 용량 입력: `ceil(목표 kW × 1000 ÷ 모듈 W)`가 최소 수량입니다. 실제 설치 수량은 직렬 구성 단위로 올림하여 목표 용량 이상으로 산정합니다. 실제 용량은 모듈 정격출력 × 설치 수량입니다. 기존 수량 입력·지도 경계 면적 방식도 유지합니다.
- 수상 선택 시 부유체·계류장치 모델, 참고 부력·설계하중, 출처를 입력합니다. 다른 유형에서는 입력란을 비활성화하고 수상 비용을 제외합니다.
- 경사각·방위각별 동일 용량의 물리 모델 발전량을 분석 결과에서 비교합니다. 선택 조건 및 남향 20°·30°, 동향·서향 30°를 제공합니다. 조건을 저장하고 **분석 실행/다시 분석**을 눌러 갱신합니다.
- 추가 음영손실을 모든 설치 유형에서 입력할 수 있습니다.
- 월별·연간 예측 발전량과 예상 매출, 비용 항목, 투자비, B/C, NPV, 필요 판매단가, 회수기간, 사업기간 순현금이익을 표시합니다. 순현금이익은 초기 투자비와 운영비·교체비를 차감한 세전·비차입 누계입니다.
- 사용자 판매단가와 SMP·REC 가격은 음수·0·기존 상한 이상도 입력 가능합니다. 유한한 숫자만 허용하며 가격을 최소 필요 단가로 강제 보정하지 않습니다. 비교단가는 쉼표로 최대 8개를 입력합니다.
- 매출은 예측 판매전력량 × 사용자 판매단가입니다. 출력제한·자가소비를 반영합니다. 월별 자가소비는 연간 자가소비를 발전량 비율로 배분한 가정입니다.
- 결과 화면·인쇄 보고서·CSV에 비용 및 판매단가 가정, 단위, 출처를 남깁니다. 후보지·설계 대안 비교는 기존 비교 화면에서 공통 목록으로 제공합니다.

## 데이터와 데모 범위

관측소 좌표 출처: https://minwon.kma.go.kr/main/obvStn.do (2026-11-14 확인). 관측소 목록은 Git에서 제외하므로 최초 실행·Docker 빌드 전에 `backend/scripts/refresh_kma_stations.py`로 생성합니다. 이 목록은 해당 공식 표의 스냅샷이며 전국 모든 AWS를 포함하지 않습니다. 원본 관측자료와 데이터 처리·검증 JSON도 별도로 보관합니다.

`data/weather/asos_daily`의 제공 CSV 11개는 파일명 대신 **본문 STN 번호**로 읽습니다. 천안(232)의 일사량은 전부 결측(-999)이므로 현재 연결 가능한 관측소는 10곳입니다. 가장 가까운 관측소가 결측이면 자료를 확보한 관측소 중 최단거리를 사용하고 차이를 명시합니다. 연결 거리가 60 km를 넘으면 대표성 확인 안내를 표시합니다. 운영 중인 기상청 API의 자동 수집은 포함하지 않습니다.

발전량은 **관측소 일자료의 월별 평균 일사량·기온 + 후보지 ERA5 시간별 분포**를 사용하는 데모입니다. 월별 평균 일일 일사량이 관측소 값에 맞도록 GHI·DNI·DHI를 같은 비율로 조정하고, 월 평균기온 차를 더합니다. 제공 관측기간(대체로 2023-04~2026-07)은 30년 평년이 아니며, 이 방식의 정확도는 검증되지 않았습니다. 기존 K-water 보정 모델과 P10–P90를 중복 적용하지 않습니다. 사용한 관측소·프로파일·변환계수는 분석 스냅샷과 결과에 기록됩니다. 자료가 없으면 ERA5 경로를 유지합니다.

다음은 데이터·상세 설계가 추가로 필요합니다.

1. 모든 최인접 관측소의 실제 시간별 기상으로 계산: 기상청 API 접근 및 일사·기온의 기간별 품질·결측 처리가 필요합니다.
2. 정밀 음영: 장애물 높이·형상, 지형·수목 데이터와 시간별 음영 모델이 필요합니다. 현재는 사용자 음영손실률입니다.
3. 부유체·계류장치 제조사 카탈로그 선택과 안전 검토: 검증된 제품 목록·부력·하중·수위 조건이 필요합니다. 현재는 사용자 제원 기록과 원/kW 비용 가정입니다.
4. 직접 입력한 면적·목표 용량의 실제 배치: 면적 계산은 직사각형 배열 가정이며 현장 경계·통로·지형에 대한 시공 검증을 대신하지 않습니다. 지도에 모두 배치되지 않는 경우 결과에서 경고합니다.

## 검증

백엔드 118개 테스트(기존 106개 + 신규 12개), 프론트엔드 51개 테스트와 production 빌드를 확인했습니다. 목표 용량 올림, 여유면적·행간, 음수·0·큰 판매단가, 관측소 좌표 선택, 관측자료 반영, 스냅샷 불변성, 월·연간 매출 일치, API 입력 검증, 지도 클릭 좌표·경계 저장, 실제 좌표의 관측소 아이콘을 확인합니다.

실제 1991~2020 ERA5 캐시를 사용하는 HTTP 검증에서 650 W 모듈·목표 100 kW는 154장·100.1 kW로 산정됐습니다. 면적 10,000 m²·여유 30%의 수상 조건, 음수 판매단가, 관측소 연결, 비용 전환, CSV 가정 출처를 확인했습니다. 재현 스크립트는 `backend/scripts/verify_feasibility.py`, 결과는 `docs/feasibility-http-verification.json`입니다.

브라우저 URL을 확인할 수 없어 컴퓨터 사용 도구가 중단되어 실제 브라우저 육안 검증은 수행하지 못했습니다. Leaflet 실제 DOM 테스트와 HTTP 검증은 별도로 수행합니다.
