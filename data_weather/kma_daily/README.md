## 모델 코드에서 쓸 때

`model_bundle.py`의 `build_monthly_training_data()`는 파일 이름에서 `지상관측데이터_` 뒤를 지역명으로 읽으므로,
새 이름에서는 `천안_232`가 됩니다. 지역명만 쓰려면 다음처럼 바꾸면 됩니다.

```python
by_city[stem[len(normalized_prefix):].split("_")[0]] = read_kma_asos_daily(path)
```
